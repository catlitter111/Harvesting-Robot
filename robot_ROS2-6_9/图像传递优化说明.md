# 图像传递优化说明

## 概述

为了降低WebSocket节点接收图像的延迟，我们引入了一个**图像桥接器（ImageBridge）**，提供函数调用方式的图像传递，同时保持与原有ROS2话题订阅方式的完全兼容性。

## 🎯 优化目标

- **降低延迟**：减少图像从检测节点到WebSocket节点的传递延迟
- **保持兼容性**：不影响现有功能，原有代码无需修改
- **提高效率**：避免不必要的序列化/反序列化开销
- **支持多接收端**：一次发送，多个节点同时接收

## 🏗️ 架构设计

### 原有方式：ROS2话题订阅
```
检测节点 → 发布压缩图像话题 → ROS2中间件 → WebSocket节点订阅
```

### 新增方式：函数直接调用
```
检测节点 → 图像桥接器 → 直接调用回调函数 → WebSocket节点
```

### 混合方式（推荐）
```
检测节点 → 同时发布到话题 + 桥接器 → 两种方式并存
```

  - 注册`direct_image_callback`回调函数
  - 保持原有ROS2话题订阅不变

### 4. 测试脚本
- **文件**: `robot_ROS2-6_9/src/bottle_detection_ros2/scripts/test_image_bridge.py`

## ⚡ 性能优势

## 🛠️ 故障排除

### 常见问题

1. **回调函数未执行**
   - 检查是否正确注册回调函数
   - 确认桥接器单例是否正常初始化

2. **延迟仍然较高**
   - 检查回调函数的执行效率
   - 确认图像数据大小是否合理

3. **内存使用增加**
   - 检查是否存在回调函数泄漏
   - 确保及时取消注册不需要的回调

## 📄 API参考

### 图像桥接器API
```python
from bottle_detection_ros2.core.image_bridge import get_image_bridge

# 获取单例实例
bridge = get_image_bridge()

# 注册回调函数
bridge.register_image_callback("my_callback", callback_func)

# 发送图像
bridge.send_image(image_data, "jpeg", timestamp, "source")

# 获取统计信息
stats = bridge.get_stats()

# 取消注册
bridge.unregister_image_callback("my_callback")
```

### 便捷函数API
```python
from bottle_detection_ros2.core.image_bridge import (
    register_image_callback,
    send_image,
    get_bridge_stats
)

# 直接使用便捷函数
register_image_callback("my_callback", callback_func)
send_image(image_data, "jpeg")
stats = get_bridge_stats()
```
