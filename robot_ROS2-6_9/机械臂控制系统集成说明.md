# 机械臂控制系统集成说明

## 系统架构

本系统实现了从微信小程序到机械臂硬件的完整控制链路：

```
微信小程序 → 服务端 → WebSocket桥接节点 → 舵机调试节点 → 舵机控制节点 → 机械臂硬件
```

### 集成系统特点

1. **无键盘依赖**: 机械臂调试节点已去除键盘控制功能，仅通过WebSocket接收控制指令
2. **完整集成**: `integrated_system.launch.py` 可一次性启动所有必要节点
3. **远程控制**: 通过微信小程序实现远程机械臂控制
4. **高可靠性**: 所有节点在同一launch文件中管理，确保启动顺序和依赖关系
5. **智能位置同步**: 自动同步舵机实际位置，避免第一次控制时的大幅移动

## 消息流转

### 1. 前端控制指令
微信小程序发送机械臂控制指令：
- `arm_rotate_up`: 机械臂向上转
- `arm_rotate_down`: 机械臂向下转
- `arm_rotate_left`: 机械臂向左转
- `arm_rotate_right`: 机械臂向右转
- `arm_stop`: 停止机械臂

### 2. WebSocket桥接节点 (`websocket_bridge_node.py`)
**功能**：
- 接收来自服务端的机械臂控制指令
- 将指令转换为ROS2内部消息格式
- 发布到 `arm_control/command` 话题

**关键修改**：
- 添加了 `arm_control_pub` 发布者
- 在 `handle_command` 中识别 `arm_rotate_*` 和 `arm_stop` 指令
- 新增 `handle_arm_control_command` 方法处理机械臂指令映射

**消息格式**：
```json
{
  "command": "arm_up|arm_down|arm_left|arm_right|arm_stop",
  "speed": 50,
  "timestamp": 1234567890
}
```

### 3. 舵机调试节点 (`servo_debug_node.py`)
**功能**：
- 订阅 `arm_control/command` 话题
- 将机械臂控制指令转换为具体的舵机移动参数
- 发布 `ServoCommand` 消息到 `servo/command` 话题

**关键修改**：
- 添加了 `arm_control_sub` 订阅者
- 新增 `arm_control_callback` 方法处理机械臂控制
- 支持基于速度的动态步长调整
- 增加了机械臂停止功能

**舵机映射**：
- `arm_up` → 垂直舵机负方向移动
- `arm_down` → 垂直舵机正方向移动
- `arm_left` → 水平舵机正方向移动
- `arm_right` → 水平舵机负方向移动
- `arm_stop` → 停止水平和垂直舵机

### 4. 舵机控制节点 (`servo_control_node.py`)
**功能**：
- 接收 `ServoCommand` 消息
- 直接控制机械臂硬件
- 提供位置反馈和状态监控

**关键修改**：
- 在 `servo_command_callback` 中添加了机械臂控制的日志记录
- 区分水平舵机(ID=0)和垂直舵机(ID=1)的控制

## 话题接口

### 输入话题
- `arm_control/command` (String): 机械臂控制指令
  - 由 WebSocket桥接节点 发布
  - 由 舵机调试节点 订阅

### 输出话题
- `servo/command` (ServoCommand): 舵机控制指令
  - 由 舵机调试节点 发布
  - 由 舵机控制节点 订阅

- `servo/status` (ServoStatus): 舵机状态反馈
  - 由 舵机控制节点 发布
  - 由 舵机调试节点 订阅

## 控制参数

### 舵机范围设置
- **水平舵机 (ID=0)**：
  - 范围：500-2500 PWM
  - 中心：1500 PWM
  - 180度旋转范围

- **垂直舵机 (ID=1)**：
  - 范围：500-1500 PWM
  - 中心：600 PWM
  - 90度旋转范围

### 速度控制
- 基础步长：50 PWM
- 速度范围：0-100%
- 动态步长 = 基础步长 × 速度因子
- 速度因子：0.1-2.0倍

## 启动命令

### 1. 启动完整集成系统（推荐）
```bash
# 启动包含机械臂调试节点的完整系统
ros2 launch bottle_detection_ros2 integrated_system.launch.py

# 或指定特定参数
ros2 launch bottle_detection_ros2 integrated_system.launch.py \
    robot_id:=robot_123 \
    ws_server_url:=ws://101.201.150.96:1234/ws/robot/robot_123 \
    servo_serial_port:=/dev/ttyS9 \
    robot_serial_port:=/dev/ttyS3
```

### 2. 单独启动舵机控制系统
```bash
# 启动舵机控制和调试节点
ros2 launch bottle_detection_ros2 servo_debug.launch.py

# 或分别启动
ros2 run bottle_detection_ros2 servo_control_node
ros2 run bottle_detection_ros2 servo_debug_node
```

### 3. 单独启动WebSocket桥接
```bash
ros2 run bottle_detection_ros2 websocket_bridge_node
```

### 4. 测试机械臂控制
```bash
# 发布测试命令
ros2 topic pub /arm_control/command std_msgs/String '{data: "{\"command\": \"arm_up\", \"speed\": 50}"}'
```

## 调试功能

### 键盘控制（servo_debug_node）
- 方向键：直接控制舵机移动
- 数字键1-9：快捷位置
- 空格键：回到中心位置
- 'h'：显示帮助信息
- 't'：测试采摘动作序列

### 日志监控
所有节点都提供详细的日志输出，便于调试：
- WebSocket桥接节点：显示收到的机械臂指令
- 舵机调试节点：显示指令转换和执行情况
- 舵机控制节点：显示具体的舵机移动操作

## 安全考虑

1. **位置限制**：所有舵机移动都会检查PWM范围限制
2. **停止功能**：支持紧急停止所有舵机运动
3. **平滑控制**：使用动态步长避免突然的大幅移动
4. **状态监控**：实时监控舵机位置和状态

## 故障排除

### 常见问题
1. **舵机不响应**：
   - 检查串口连接 (`/dev/ttyS9`)
   - 确认波特率设置 (115200)
   - 查看舵机控制节点日志

2. **WebSocket连接问题**：
   - 确认服务端运行状态
   - 检查网络连接
   - 查看桥接节点日志

3. **控制延迟**：
   - 检查网络延迟
   - 调整控制频率参数
   - 优化步长设置

4. **第一次控制移动角度过大**（已修复）：
   - **问题描述**: 点击开始采摘后，第一次机械臂控制移动角度很大
   - **原因**: 调试节点记录的位置与舵机实际位置不同步
   - **解决方案**: 
     - 节点启动时自动同步位置
     - 第一次控制前强制同步位置
     - 改进位置监控机制（阈值从50降至30PWM）
   - **验证**: 查看日志中的"位置已同步"信息

### 日志检查
