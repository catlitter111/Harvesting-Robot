# 手动模式控制类型切换功能说明

## 功能概述

在微信小程序的手动控制模式下，新增了电机控制和机械臂控制的切换功能，用户可以根据当前需要的操作类型选择相应的控制模式。

## 主要功能

### 1. 控制类型切换
- **电机控制**：控制机器人底盘移动和基础动作
- **机械臂控制**：控制机械臂进行精确定位和抓取操作

### 2. 界面显示
- 在手动模式下显示控制类型选择开关
- 提供清晰的状态指示和功能描述
- 实时显示当前选择的控制类型
- 机械臂控制模式下按钮显示橙色并带有方向标签（上转、下转、左转、右转）

### 3. 命令区分
- 根据控制类型发送不同的控制命令
- 电机控制：发送标准移动命令（forward, backward, left, right）
- 机械臂控制：发送机械臂旋转命令（arm_rotate_up, arm_rotate_down, arm_rotate_left, arm_rotate_right）

## 代码修改详情

### 1. JavaScript文件修改 (`control.js`)

#### 新增数据字段
```javascript
// 控制类型：'motor' 电机控制，'arm' 机械臂控制
controlType: 'motor',        // 默认为电机控制
```

#### 新增切换函数
```javascript
// 切换控制类型：电机控制 / 机械臂控制
switchControlType: function(e) {
  const newType = e.detail.value ? 'arm' : 'motor';
  
  this.setData({
    controlType: newType
  });
  
  // 发送控制类型切换命令
  this.sendCommand('switch_control_type', {
    control_type: newType
  });
  
  wx.showToast({
    title: newType === 'arm' ? '已切换至机械臂控制' : '已切换至电机控制',
    icon: 'none',
    duration: 1500
  });
  
  console.log('控制类型已切换为:', newType === 'arm' ? '机械臂控制' : '电机控制');
}
```

#### 修改命令发送逻辑
```javascript
// 为移动相关命令添加速度参数和控制类型
if (['forward', 'backward', 'left', 'right'].includes(command)) {
  params.speed = this.data.motorSpeed;
  params.control_type = this.data.controlType;
  
  // 根据控制类型修改命令名称
  if (this.data.controlType === 'arm') {
    command = 'arm_' + command;
  }
}
```

## 使用方法

### 1. 进入手动模式
1. 打开微信小程序控制页面
2. 将操作模式切换为"手动模式"

### 2. 切换控制类型
1. 在手动控制面板顶部找到"控制类型"区域
2. 使用开关切换电机控制和机械臂控制
3. 观察描述文字的变化确认当前模式

### 3. 执行控制操作
1. 选择相应的控制类型后
2. 使用方向控制按钮进行操作
3. 系统会根据当前控制类型发送对应的命令

## 命令协议

### 电机控制命令
- `forward`: 前进
- `backward`: 后退  
- `left`: 左转
- `right`: 右转
- `stop`: 停止

### 机械臂控制命令
- `arm_rotate_up`: 机械臂向上转
- `arm_rotate_down`: 机械臂向下转
- `arm_rotate_left`: 机械臂向左转
- `arm_rotate_right`: 机械臂向右转
- `stop`: 停止（通用）

### 控制类型切换命令
- `switch_control_type`: 切换控制类型
  - 参数：`control_type` (值为 'motor' 或 'arm')

## 机械臂控制详细说明

### 🤖 **按钮功能映射**

当选择机械臂控制模式时，方向按钮的功能如下：

- **↑ 上转**: 机械臂向上旋转，用于调整抓取高度（发送 `arm_rotate_up` 命令）
- **↓ 下转**: 机械臂向下旋转，降低抓取位置（发送 `arm_rotate_down` 命令）
- **← 左转**: 机械臂向左旋转，调整水平角度（发送 `arm_rotate_left` 命令）
- **→ 右转**: 机械臂向右旋转，调整水平角度（发送 `arm_rotate_right` 命令）
- **■ 停止**: 立即停止机械臂所有动作（发送 `stop` 命令）

### 🎨 **视觉反馈**

- 按钮在机械臂模式下会变为**橙色**主题色
- 显示相应的**动作标签**（上转、下转、左转、右转）
- 控制类型描述会更新为"控制机械臂旋转：上下左右转动进行精确定位"
- 开关指示器显示当前选择的控制类型

### ⚙️ **技术实现**

1. **命令映射**: 前端自动将 `forward/backward/left/right` 转换为 `arm_rotate_*` 命令
2. **服务端处理**: 服务端识别 `arm_rotate_*` 命令并提供相应的日志和反馈
3. **参数传递**: 包含速度和控制类型参数，便于后端区分处理
