# 本地控制界面使用指南

## 概述

本地控制界面是一个基于Tkinter的图形用户界面，用于在机器人本地直接控制和监控智慧农业采摘系统。该界面完全按照您的设计要求实现，包含系统控制、实时监控、状态显示和数据统计等功能。

## 功能特性

### 🎮 控制中心
- **系统启停控制**：一键启动/停止 `integrated_system.launch.py`
- **工作模式切换**：手动/自动模式切换
- **采摘控制**：开始/停止采摘作业
- **紧急停止**：立即停止所有操作的安全按钮
- **今日成果显示**：实时显示当日采摘数量

### 📹 实时监控
- **视频流显示**：摄像头处理后的实时画面
- **检测信息**：目标数量、最近距离、检测准确率
- **FPS监控**：实时帧率显示

### 🔧 系统状态
- **电池电量**：电量百分比和可视化进度条
- **CPU使用率**：系统负载监控
- **系统温度**：工作温度显示
- **位置信息**：GPS坐标和区域描述
- **工作状态**：工作时长、移动速度等

### 🌾 农场数据总览
- **累计采摘**：历史总采摘量
- **作业精度**：工作准确率统计
- **信号强度**：网络连接状态
- **运行天数**：系统运行时间
- **健康状态**：设备健康评估

## 安装依赖

在运行界面之前，请确保安装以下依赖：

```bash
# Python图像处理库
pip install Pillow opencv-python

# 确保tkinter已安装（通常随Python安装）
# Ubuntu系统可能需要：
sudo apt-get install python3-tk
```

## 启动方式

### 方式一：使用ROS2命令启动
```bash
# 进入ROS2工作空间
cd /path/to/your/ros2_workspace

# source环境
source install/setup.bash

# 启动本地控制界面
ros2 run bottle_detection_ros2 local_control_gui
```

### 方式二：直接运行Python脚本
```bash
# 使用启动脚本
python3 /path/to/scripts/start_local_gui.py

# 或者直接运行主程序
python3 -c "from bottle_detection_ros2.gui.local_control_gui import main; main()"
```

## 使用说明

### 启动系统
1. 点击"启动系统"按钮
2. 系统将自动启动 `integrated_system.launch.py`
3. ROS2节点开始订阅相关话题
4. 界面开始显示实时数据

### 控制操作
- **切换工作模式**：点击"手动"或"自动"按钮
- **开始采摘**：点击"🍎 开始采摘"按钮
- **紧急停止**：红色"⭕ 紧急停止"按钮，立即停止所有操作

### 监控数据
- 所有数据都通过ROS2话题实时更新
- 视频流来自 `/camera/processed_image/compressed`
- 检测结果来自 `/bottle_detection`
- 系统状态来自 `/robot_status`

## 订阅的ROS2话题

| 话题名称 | 消息类型 | 功能描述 |
|---------|---------|---------|
| `/camera/processed_image/compressed` | `sensor_msgs/CompressedImage` | 处理后的摄像头图像 |
| `/bottle_detection` | `bottle_detection_msgs/BottleDetection` | 瓶子检测结果 |
| `/robot_status` | `bottle_detection_msgs/RobotStatus` | 机器人状态信息 |
| `/camera/fps` | `std_msgs/Float32` | 摄像头FPS信息 |

## 发布的ROS2话题

| 话题名称 | 消息类型 | 功能描述 |
|---------|---------|---------|
| `/robot_command` | `bottle_detection_msgs/RobotCommand` | 机器人控制命令 |
| `/harvest_command` | `bottle_detection_msgs/HarvestCommand` | 采摘控制命令 |
| `/work_mode` | `std_msgs/String` | 工作模式切换 |

## 错误处理

所有函数都包含完整的异常处理，使用`traceback`模块显示详细的错误堆栈信息：

- 界面创建失败时会显示详细错误信息
- ROS2连接问题会在控制台输出调试信息
- 图像处理错误不会影响界面正常运行
- 系统启停过程中的异常会被妥善处理

## 注意事项

1. **权限要求**：启动launch文件可能需要相应的系统权限
2. **依赖检查**：确保所有ROS2节点正常运行
3. **显示设备**：需要连接显示器或配置X11转发
4. **性能考虑**：图像处理会占用一定CPU资源
5. **网络连接**：某些功能需要网络连接支持

## 故障排除

### 界面无法启动
- 检查Python依赖是否完整安装
- 确认ROS2环境是否正确source
- 检查tkinter是否可用

### 无法接收数据
- 确认相关ROS2节点是否运行
- 检查话题名称是否正确
- 使用`ros2 topic list`验证话题存在

### 视频显示异常
- 检查摄像头节点是否正常工作
- 确认图像话题是否有数据发布
- 检查opencv和PIL库是否正确安装

## 开发扩展

如需扩展功能，可以修改以下文件：
- `local_control_gui.py` - 主界面逻辑
- `start_local_gui.py` - 启动脚本
- `setup.py` - 包配置文件

所有代码都有详细注释，便于理解和修改。
