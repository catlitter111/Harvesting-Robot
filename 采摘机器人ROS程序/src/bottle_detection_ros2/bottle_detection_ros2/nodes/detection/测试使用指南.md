# 瓶子检测调试图像保存功能测试指南

## 快速测试步骤

### 1. 启动瓶子检测节点
```bash
# 进入ROS2工作空间
cd robot_ROS2-6_9

# 启动检测节点（带调试图像保存功能）
ros2 run bottle_detection_ros2 integrated_bottle_detection_node
```

### 2. 启动自动采摘控制器
```bash
# 在另一个终端
ros2 run bottle_detection_ros2 auto_harvest_controller
```

### 3. 模拟采摘过程
当系统检测到瓶子并到达采摘距离时，会自动截取图像并保存到：
`~/bottle_detection_debug_images/`

### 4. 查看保存的调试图像

#### 方法1: 使用快速查看脚本
```bash
cd robot_ROS2-6_9/src/bottle_detection_ros2/bottle_detection_ros2/nodes/detection
./quick_view.sh
```

#### 方法2: 使用Python查看器
```bash
# 查看最新的图像集
python3 view_debug_images.py --latest

# 查看最近5个图像集
python3 view_debug_images.py --count 5

# 不显示详细信息
python3 view_debug_images.py --no-details
```

#### 方法3: 直接浏览文件
```bash
# 打开文件管理器查看
nautilus ~/bottle_detection_debug_images
```

## 目录结构说明

```
~/bottle_detection_debug_images/
├── cropped_bottles/        # 截取的瓶子图像和信息文件
├── full_frames/           # 完整的原始图像
└── annotated_frames/      # 带标注的图像
```

## 文件说明

每次截取会生成4个文件：
1. **bottle_crop_*.jpg** - 截取的瓶子图像（发送给AI的内容）
2. **full_frame_*.jpg** - 完整的原始图像
3. **annotated_*.jpg** - 带标注的图像（显示截取区域）
4. **crop_info_*.txt** - 详细的截取信息和参数

## 调试建议

### 1. 检查截取精度
查看 `annotated_frames/` 中的图像：
- 红色框：原始检测边界框
- 绿色框：实际截取区域
- 确认绿色框正确包含了瓶子

### 2. 分析截取图像质量
查看 `cropped_bottles/` 中的图像：
- 图像是否清晰
- 瓶子是否完整
- 是否有多余的背景

### 3. 检查截取参数
查看 `crop_info_*.txt` 文件：
- 边界框坐标是否合理
- 截取尺寸是否适当
- 边距设置是否合适

## 常见问题

### Q: 没有生成调试图像
**A:** 确认以下几点：
1. 检测节点正常运行
2. 检测到瓶子并触发采摘
3. `debug_save_images = True` 在代码中
4. 对保存目录有写权限

### Q: 图像查看器无法显示
**A:** 确认：
1. 安装了OpenCV: `pip install opencv-python`
2. 有图形界面环境
3. 调试目录存在并有图像文件

### Q: 截取的图像质量不好
**A:** 可以调整：
1. 截取边距（在代码中修改 `margin` 参数）
2. 检测置信度阈值
3. 图像压缩质量

## 关闭调试功能

如不需要保存调试图像，可以：
1. 修改代码中的 `self.debug_save_images = False`
2. 或者注释掉保存相关的代码块

这样可以减少磁盘占用和提高性能。
